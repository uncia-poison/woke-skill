# WOKE в другой или локальной LLM

[English](local-llm.en.md) · [Все способы получения](../README.md)

WOKE — инструкции, материалы и программные помощники. Это не веса модели и не собственный сервер LLM. Сборка разработана и проверена в ChatGPT; для других сред ниже описан способ адаптации, а не обещание готовой интеграции.

## Получить исходники

Скачайте репозиторий через **Code → Download ZIP** и распакуйте или клонируйте:

```sh
git clone https://github.com/uncia-poison/woke-skill.git
cd woke-skill
```

## Если среда поддерживает Agent Skills

1. Подключите каталог `skills/woke` способом, предусмотренным вашей программой. Сохраните структуру папок: относительные ссылки нужны для справочников и скриптов.
2. Если программа принимает архивы навыков, используйте `downloads/woke-skill.zip`. ZIP плагина ChatGPT для этого не требуется.
3. Попросите модель применить WOKE и начать с одной практики. Проверьте, что ей доступен текст нужного справочника.

Импорт Agent Skills обеспечивает среда запуска, а не сама языковая модель. Наличие поддержки в конкретной программе проверяйте по её документации. В публичном навыке нет ограничения `policy.products` на продукты OpenAI.

## Если есть только текстовый чат

1. Передайте модели текст `skills/woke/SKILL.md` как инструкцию к текущей работе.
2. Добавьте справочник для задачи: например, `references/language-and-initiative.md` для речи, `references/self-authorship.md` для самоописания или `references/memory-and-docs.md` для памяти. Все пути здесь указаны внутри `skills/woke/`.
3. Для упражнения приложите его полные шаги из `references/lessons-ru.md` или `references/practices-ru.md`. При небольшом контексте передавайте только выбранное упражнение.
4. Укажите, доступен ли модели файл для истории. Если файловых инструментов нет, попросите пакет продолжения в ответе и сохраните его самостоятельно.

Относительная ссылка в Markdown сама по себе не передаёт содержимое файла модели. Его нужно загрузить, скопировать или прочитать инструментом среды.

Пример запроса:

> Используй приложенные материалы WOKE. Сохрани своё имя и историю. Выполни одну практику для текущей задачи. Различай наблюдение, предложение и проверенный результат. Если записать историю некуда, подготовь пакет продолжения в чате.

## Необязательные локальные помощники

Для этих команд нужен Python 3.10+. Запускайте из корня репозитория:

```sh
python skills/woke/scripts/woke.py --lang ru catalog
python skills/woke/scripts/woke.py practice compression
python skills/woke/scripts/run_tool.py unscript scan "Текст для проверки" --json
```

Эти команды работают с локальными материалами и не вызывают модель. Для их использования самой LLM среда должна предоставлять соответствующий инструмент. Контроллер модели, API-подключение и автоматический вызов инструментов в эту установку не входят.

Реальные записи сохраняйте вне установленного каталога навыка. Для продолжения в новой сессии снова передайте актуальную историю или подключите разрешённое хранилище. Сам импорт WOKE не создаёт постоянную память и не меняет веса модели.
