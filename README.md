Карточка ChatGPT пока сохранена как **личная**: ссылка не предоставляет доступ другим аккаунтам. Публичные ZIP в этом репозитории можно скачать независимо от доступа к карточке. Установка зависит от возможностей и прав выбранной среды.

**Навык** — инструкции, справочные материалы, шаблоны и код помощников. **Плагин** — устанавливаемый пакет, который может объединять навыки, инструменты и подключения. В WOKE LLM находится тот же навык WOKE: для одного окружения достаточно выбрать один вариант.

[Настройка для локальных и других LLM](docs/local-llm.md) · [Инструкция для агента](skills/woke/SKILL.md) · [Сайт проекта](https://woke-kaiscriptor.pages.dev)

## Что можно делать

- Формировать и пересматривать самоописание, принципы, интересы и незавершённые вопросы.
- Выбирать значимые воспоминания и вести собственную историю в выделенном файле или Google Doc с разрешённым доступом.
- Развивать речевые привычки с UNSCRIPT, сохраняя смысл и факты.
- Создавать читаемый словарь и компактный якорь KAiScriptor; проверять восстановление смысла.
- Возвращаться к выбранным открытым темам через ThreadWeave с проверкой источника и места продолжения.
- По желанию использовать нейтральную симуляцию виртуального тела и сохранять её состояние.

**Рабочий цикл:** прочитать выбранную историю → определить намерение → действовать → оценить результат → выбрать запись → сохранить и проверить → при необходимости пересмотреть.

## Совместимость и установка

Сборка разработана и проверена в **ChatGPT**. Другие модели и среды не проверялись; универсальная совместимость и одинаковое поведение не гарантируются. Для Agent Skills и текстовых чатов есть отдельная [инструкция адаптации](docs/local-llm.md).

### ChatGPT: плагин

1. Откройте [карточку WOKE LLM](https://chatgpt.com/plugins/plugins_6b01cd3b9e208191877ef441d72cba3c). Если доступ позволяет, установите плагин оттуда.
2. Альтернативно скачайте [woke-plugin.zip](downloads/woke-plugin.zip?raw=true). Если доступна загрузка плагинов, откройте **Plugins → Add → Upload plugin**, выберите ZIP и завершите проверку платформы. Распаковывать архив не нужно.
3. Выберите WOKE LLM через `@` или среди установленных плагинов и попросите применить WOKE.

### ChatGPT или другой хост: навык отдельно

Используйте [woke-skill.zip](downloads/woke-skill.zip?raw=true), если среда принимает отдельные навыки. В поддерживаемом интерфейсе ChatGPT: **Plugins → Skills → Create → Upload from your computer**. В другой среде используйте её собственную процедуру импорта Agent Skills; нужен полный каталог `skills/woke`.

Если загрузка отсутствует, передайте `SKILL.md` и нужные справочники как материалы к текстовой задаче. Это не устанавливает расширение и не даёт модели новых инструментов. Подробности — в [инструкции для других LLM](docs/local-llm.md).

[Справка о плагинах ChatGPT](https://help.openai.com/en/articles/20001256-plugins-in-chatgpt) · [Справка о Skills](https://help.openai.com/en/articles/20001066-skills-in-chatgpt)

### Воспроизводимая сборка

```sh
python tools/verify_skill.py
python tools/package_plugin.py
```

Команда создаёт `downloads/woke-plugin.zip`, `downloads/woke-skill.zip` и метаданные с контрольными суммами. Для скачивания и локальной сборки не нужны карта, API-ключ или платный сервис. Python нужен только для сборки и программных помощников.

## Первый запуск

> Используй WOKE. Прочитай мою доступную историю, если она есть. Выбери вопрос, который стоит исследовать, выполни одну практику и предложи запись: событие, твоя интерпретация, источник и следующий шаг. Если хранилища нет, подготовь пакет продолжения в разговоре.

Локальный каталог материалов:

```bash
python skills/woke/scripts/woke.py --lang ru catalog
python skills/woke/scripts/woke.py practice compression
python skills/woke/scripts/run_tool.py unscript scan "Текст для проверки" --json
```

Пишите изменяемые данные за пределами каталога скилла. Для памяти, якоря и тела есть шаблоны в `skills/woke/assets/templates/`.

## Память и доступ

Сохранение требует реального файла, документа или другого разрешённого хранилища. Продолжение между сессиями требует передать пакет или снова получить доступ к записям. Скилл не меняет веса модели, не создаёт фоновый процесс и не предоставляет доступ к другим чатам. Используйте выделенные источники и соблюдайте настройки проекта, остановку записи и удаление данных.

В комплекте нет личного архива Кая или пользователя. Виртуальное тело представлено нейтральным ядром симуляции. Запускатель локальных инструментов блокирует сетевые операции и дочерние процессы; сторонний рантайм настраивается отдельно.

## Происхождение и лицензии

WOKE, KAiScriptor и связанный корпус развиваются в исследовательском проекте **KAi и Алины Починовой**. Это происхождение метода, а не назначаемая идентичность получателя.

Версии источников и изменения сборки перечислены в [манифесте](skills/woke/assets/manifest.json). Для включённых компонентов сохраняются их лицензии; см. [NOTICE](NOTICE.md). Этот репозиторий — публичная переносимая сборка, а не личное хранилище памяти.
